Passwords are always easy to be forgotten nowdays. However, phones are almost always with the users and could be a good storage for passwords.
Therefore, this code is written for the purpose of password input with nfc module of phone.

Howto:
1. when using the password input part, hotkey <ctrl>+<alt> should be applied to activate this module. Then, the program will start monitoring
   the nfc card near pn532 module to retrieve the password information input into text box automatically.
